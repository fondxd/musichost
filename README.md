# Music Pro & Host

Full-capability self-hosted music streaming and lossless downloading player.

## Features
- 🏆 **65+ Global Charts & Rankings**: Surging, New Releases, Hot 200, Billboard, Oricon, UK Top 40, K-Pop, EDM, Hip-Hop, and ACG.
- 💎 **Multi-Format Downloads**: One-click download in FLAC Lossless, High Quality MP3 320K, Standard MP3 128K, or Synced LRC Lyrics.
- 💬 **Karaoke Lyrics**: Real-time synchronized scrolling lyrics with tap-to-seek timestamp jumping.
- 📜 **Queue Management**: Full playlist queue with shuffle, repeat-all, and repeat-one modes.
- 📱 **Mobile Optimized**: iOS lock screen MediaSession controls, background streaming, and touch-friendly UI.
- 🔍 **Multi-Source Search**: Unified search across NetEase, Kuwo, KuGou, and local Mac libraries.
